# Borradores de guías

Acá quedan las guías escritas por las tareas programadas hasta que Damián las aprueba.
El build solo lee `contenido/*.html` (no esta carpeta) y `contenido/` no se publica, así que nada de acá aparece en la web.
Con el OK: `git mv contenido/borradores/guia-<slug>.html contenido/`, correr `python3 tools/build_contenido.py`, commit y push.
Si se descarta: borrar el archivo.
